# Partner portal MVP (reference only, on hold)

The client's university portal from the original Vernyr build (plain JS front end on Express + SQLite).
Kept here so it is not lost; it does not run in this monorepo and is excluded from the TypeScript build.
It is the feature spec for the `partner/` Next app when work on it resumes.

- `public-university/`  front end (dashboard, applications, pipeline, courses, intakes, letters, finance, reports, users)
- `server-university/`  API, auth, approvals, letters / PDFs, jobs, emails
- `university_staff.js` La Europa admin side (accounts, agreements, approvals, commission)
- `university.test.js`  the rules it was tested against
